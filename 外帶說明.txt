# Telemini callback run_reply_recovery 修正包

## 修正錯誤

Render log：
UnboundLocalError: cannot access local variable 'run_reply_recovery' where it is not associated with a value

原因：
handlers/call_handler.py 的 handle_ui() 內部在 blocked_reply_debug 分支有：
from services.call_ai import run_reply_recovery

Python 會因此把 run_reply_recovery 判定成 handle_ui() 的區域變數。
前面的 ai_reply / hidden_ai_reply 分支先使用 run_reply_recovery 時，區域變數尚未被賦值，所以爆掉。

## 修改檔案

- handlers/call_handler.py

## 修改方式

1. 把 run_reply_recovery 移到檔案頂部 import。
2. 移除 handle_ui() 裡面的區域 import。

## 覆蓋位置

把本包的：
handlers/call_handler.py

覆蓋到專案的：
handlers/call_handler.py

## 已測試

python -m py_compile handlers/call_handler.py
