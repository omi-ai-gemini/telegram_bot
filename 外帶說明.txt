Telemini /hidden Reply Keyboard 轉瞬即逝修正包

只包含修改檔，不是全專案。

覆蓋檔案：
- services/ai_actions.py

修正問題：
上一版 /hidden 送出 Reply Keyboard 後，會在 1.5 秒後刪除「開發者功能鍵盤已開啟」提示訊息。
Telegram 的 Reply Keyboard 是靠這則 bot 訊息套用到使用者輸入框下方，部分 Telegram 用戶端在該訊息被刪除後，會把鍵盤一起收回。
所以會看到開發者鍵盤轉瞬即逝，還沒來得及按就回到普通鍵盤。

本版修正：
- /hidden 指令訊息仍會刪除。
- 「開發者功能鍵盤已開啟」提示訊息不再立刻刪除。
- 提示訊息會等使用者按任一功能鍵或「關閉功能鍵盤」時，由 _close_hidden_keyboard() 一起刪除。
- 功能鍵按出的 emoji 訊息仍會刪除。
- 執行功能後仍會收起鍵盤。

已做檢查：
python -m py_compile services/ai_actions.py

測試：
1. 輸入 /hidden。
2. 確認輸入框下方鍵盤會停留。
3. 按 🗣️ / ✏️ / 🔁 / 🧠 / ▶️ 或「關閉功能鍵盤」。
4. 確認提示訊息與按鍵文字會被清掉，鍵盤會收起。
