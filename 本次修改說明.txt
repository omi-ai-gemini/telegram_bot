Telemini 生圖任務解析重寫外帶包

這包不是只換一句 prompt，而是重寫「副模型整理圖片 prompt」的流程，並補上模式分流。

本次修改重點
1. 保留目前生成模式
   - 文生圖
   - 文生圖＋基準圖（原本勾選啟用基準圖）
   - 整體圖生圖
   - 局部遮罩修改

2. 副模型改成先做「中文任務解析」，再輸出英文圖片 prompt
   - 不再直接把使用者原句先翻譯成英文再整理
   - 先用中文理解需求，再輸出結構化 JSON
   - JSON 會拆出：
     * must_keep
     * must_change
     * must_not_change
     * must_not_add
     * low_priority_fill
     * final_positive_prompt
     * final_negative_prompt

3. 明確優先順序
   A. 使用者明確要求修改或限制不動的內容（最高優先）
   B. 來源圖 / 基準圖原本存在且未要求修改的內容
   C. 必要但未指定的補完（最低優先）

4. 不同模式走不同的副模型任務描述
   - text_to_image
   - reference_text_to_image
   - full_image_edit
   - mask_edit

5. 副模型失敗時仍可 fallback
   - 若副模型沒有正確輸出 JSON，會退回舊版英文化整理
   - 不會直接卡死整個生圖流程

6. 模型分流補強
   - txt2img：AI_HORDE_TXT2IMG_MODEL
   - 文生圖＋基準圖：AI_HORDE_REFERENCE_IMG2IMG_MODEL
   - 整體圖生圖：AI_HORDE_IMG2IMG_MODEL
   - 局部遮罩：AI_HORDE_INPAINT_MODEL

7. 基準圖專用 profile
   - 文生圖勾選啟用基準圖時，request_profile 會變成 text_reference
   - 會使用專門的 reference img2img 模型與參數

8. 參數補強
   - 新增 AI_HORDE_REFERENCE_IMG2IMG_MODEL
   - 新增 AI_HORDE_REFERENCE_IMG2IMG_STEPS
   - 新增 AI_HORDE_REFERENCE_IMG2IMG_CFG_SCALE
   - 新增 AI_HORDE_REFERENCE_DENOISING_STRENGTH
   - 新增 AI_HORDE_REFERENCE_DENOISE_POSE

建議可選環境變數
AI_HORDE_TXT2IMG_MODEL=AlbedoBase XL (SDXL)
AI_HORDE_REFERENCE_IMG2IMG_MODEL=Realistic Vision
AI_HORDE_IMG2IMG_MODEL=Realistic Vision
AI_HORDE_INPAINT_MODEL=Realistic Vision Inpainting

AI_HORDE_REFERENCE_IMG2IMG_STEPS=28
AI_HORDE_REFERENCE_IMG2IMG_CFG_SCALE=5.2
AI_HORDE_REFERENCE_DENOISING_STRENGTH=0.76
AI_HORDE_REFERENCE_DENOISE_POSE=0.84
