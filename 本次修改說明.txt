Telemini Qwen／ComfyUI 隱私閘道版

本次完成：

一、Render 不再需要直接連接 11434／8188
- 新增 services/local_ai_gateway_client.py。
- Qwen 與 ComfyUI 都可改走 LOCAL_AI_GATEWAY_URL。
- 遠端網址不是 HTTPS 時會拒絕連線。
- LOCAL_AI_GATEWAY_URL 或密鑰只填一半時，不會偷偷退回不安全直連。

二、本機驗證閘道
新增「本機AI閘道」資料夾：
- app.py
- 啟動本機AI閘道.cmd
- 閘道設定範例.cmd
- 產生共用密鑰.ps1
- Cloudflare Tunnel 設定範例與說明

驗證方式：
- HMAC-SHA256
- 請求時間戳
- 一次性 nonce，防重放
- request body SHA-256
- 可再疊加 Cloudflare Access Service Token

三、圖片不保存在你的電腦或 Render
- ComfyUI 工作流使用 PreviewImage，不使用 SaveImage。
- Render 只在記憶體接收圖片 bytes，不寫入磁碟。
- 本機閘道把圖片 bytes 交出去後，立即刪除 ComfyUI temp 檔。
- 同時刪除該 prompt 的 ComfyUI history。
- 閘道啟動時會清理舊 history。
- 每 10 分鐘清理超過 30 分鐘的殘留 temp 檔，處理斷線或程式中止情況。

四、圖片管理照常保留
- Telegram 成功收到圖片後，仍保存 Telegram file_id 到原本圖片管理。
- 不保存圖片實體 bytes。
- 使用者仍可在原本圖片管理查看、改名、刪除與後續圖生圖。

五、圖片管理網頁防外流
- 原本 20 分鐘簽章 token 驗證保留。
- 新增 no-store、no-cache。
- 新增 Referrer-Policy: no-referrer。
- 新增 X-Frame-Options: DENY。
- 圖片預覽不會建立公開靜態網址。

六、你需要做的一次性設定
1. 本機建立閘道共用密鑰。
2. 建立 Cloudflare Tunnel，指向 127.0.0.1:8787。
3. Render 填 LOCAL_AI_GATEWAY_URL 與 LOCAL_AI_GATEWAY_SECRET。
4. 建議再建立 Cloudflare Access Service Token。

日常不用手動驗證；程式會自動簽章與驗證每次請求。
