# 固定身份提示詞生圖更新

本版以最新版 `telemini(3).zip` 為基礎重新合併。

## 流程

- 系統預設人物：固定身份提示詞 → Flux txt2img。
- 聊天室圖片／臨時上傳圖：玩家圖片 → 等比例裁切 → Flux img2img。
- 不再使用系統基準圖、遮罩或 inpainting。

## 提示詞優先級

完全自訂提示詞 > 補充提示詞 > 固定標籤 > 本輪訊息 > 系統預設外觀。

補充提示詞明確指定髮色、髮長或髮型時，程式會先從本輪訊息移除同欄位的舊描述，避免同時出現「黑色長髮」和「金色短髮」。

玩家使用自己的參考圖片時，不套用系統固定臉型。

## 最終尺寸

固定為 896×1152。玩家參考圖先等比例裁切，不直接拉伸。
