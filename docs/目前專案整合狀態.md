# Telemini 目前專案整合狀態

本版已整理成單一路線，保留以下功能：

- Gemini 主模型聊天／劇場回覆
- AI Horde 副文字模型與 `/modes_api`
- 安全阻擋後主副模型競速
- 圖片 Prompt 先由副模型整理
- 圖生圖原圖等比例縮放、不裁切
- 依原圖比例自動選擇不超過安全像素量的 64 倍數尺寸
- 淺灰色補邊
- AI Horde 文生圖／圖生圖
- 服務中心、公告推播、Telemini Wifi、Gemini API 設定
- 圖片解析、貼圖解析、圖片庫、記憶與 Prompt Debug

## 生圖正確流程

```text
使用者送出生圖表單
→ Telegram 顯示「prompt生成中」
→ AI Horde 副文字模型整理圖片 Prompt
→ 成功：使用整理後 Prompt
→ 失敗：保留原始 Prompt 當 fallback
→ Telegram 更新為「生圖任務已送出，正在加入排隊」
→ AI Horde 圖片模型開始排隊與生成
```

## 圖生圖尺寸流程

```text
任意尺寸原圖
→ 修正 EXIF 方向
→ 保留完整原圖比例
→ 依安全總像素量選最大可用尺寸
→ 寬高向下修成 64 的倍數
→ 等比例縮放，不裁切
→ 不足區域使用 RGB(240,240,240) 淺灰補邊
→ 以動態寬高送入 AI Horde
```
