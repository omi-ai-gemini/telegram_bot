# 圖片等待函式匯入錯誤修正

## 錯誤

```text
ImportError: cannot import name 'queue_text_for_pending_photo' from 'services.media_ai'
```

原因：`handlers/message_handler.py` 已使用圖片等待 10 秒流程，但後續補丁把 `services/media_ai.py` 覆蓋成未包含等待函式的版本。

## 本次修正

只需要覆蓋：

- `services/media_ai.py`

保留並合併：

1. `queue_text_for_pending_photo()` 圖片後補文字緩衝。
2. 圖片解析完成後等待 10 秒。
3. 圖片解析上限 `65536`。
4. 靜態貼圖上限 `500`。
5. `MAX_TOKENS` 有部分圖片描述時繼續使用，並保留 log。
6. Gemini 沒有輸出圖片描述時，聊天室提示：

```text
不小心超過單次最大限制，消耗圖片次數1次，文字回應一併停止
```

7. 當日圖片額度用完時，傳圖仍會收到提示。
8. 圖片失敗時，解析期間緩衝的文字直接中斷，不另行呼叫文字模型。

## 測試

```powershell
python -m py_compile services\media_ai.py handlers\message_handler.py services\gemini_service.py config.py main.py
```
