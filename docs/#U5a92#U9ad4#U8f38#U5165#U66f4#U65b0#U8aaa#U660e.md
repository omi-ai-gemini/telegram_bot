# Telemini 非文字輸入分流更新

## 更新內容

1. 靜態貼圖
- Telegram static sticker 下載 WebP。
- 使用 `gemini-3.1-flash-lite` 解析貼圖內容。
- 再把解析結果交回原本聊天流程，由主模型自然回覆。

2. 圖片訊息
- 使用者直接傳 photo 時，不再沉默。
- 先使用 `gemini-2.5-flash` 解析圖片。
- 再把圖片解析文字交回 `gemini-3.1-flash-lite` 原聊天流程回覆。
- 這樣保留「文字回覆由 3.1 處理」的主架構。

3. 未支援輸入防呆
- 語音、音訊、影片、GIF / animation、動態貼圖、影片貼圖、文件、位置等尚未支援的訊息，會直接回覆：

```text
程式尚不能對語音、動態貼圖、影片產生回覆
```

避免使用者傳了之後聊天室完全沒有反應。

## 修改檔案

- `config.py`
- `main.py`
- `services/telegram_service.py`
- `services/gemini_service.py`
- `services/media_ai.py`

## 環境變數

可選：

```text
GEMINI_VISION_MODEL=gemini-2.5-flash
```

不設定時預設使用 `gemini-2.5-flash` 做圖片解析。

## 測試

```bash
python -m py_compile main.py config.py services/telegram_service.py services/gemini_service.py services/media_ai.py
```
