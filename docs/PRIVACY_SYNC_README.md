# Telemini 隱私同步加密包

這包不是只有發資料庫密碼，而是把「鑰匙」和「鎖」同步接起來。

## 新增流程

1. 使用者第一次傳訊息時，系統發放個別資料庫密碼。
2. 同一時間，該密碼會暫存在 Render 記憶體 unlock cache。
3. 後續新寫入的：
   - 短期記憶
   - 長期記憶
   - 劇本設定
   - 聊天人物設定
   - 回覆風格設定
   會寫入 `encrypted_settings.encrypted_payload`。
4. 舊明文資料會在使用者解鎖後遷移到 `encrypted_settings`，並從舊明文欄位刪除或清空。

## 重要限制

DB 不保存使用者資料庫密碼明文。

所以 Render 重啟後，系統不會知道使用者密碼。使用者需要私訊 bot：

```text
/解鎖 你的資料庫密碼
```

重新解鎖後，才會恢復讀取 / 寫入加密資料。

## 指令

```text
/解鎖 你的資料庫密碼
/鎖定
```

請不要在群組輸入 `/解鎖 密碼`，程式會阻擋並提醒改私訊。

## Supabase 會看到什麼

會看到：

- `privacy_access`：是否已發放密碼，不存密碼明文
- `encrypted_settings.encrypted_payload`：密文 JSONB
- 舊資料表的敏感欄位會在遷移後被清空

## 若仍看到明文

代表那筆資料尚未被該使用者解鎖遷移。請讓使用者私訊 bot：

```text
/解鎖 他的資料庫密碼
```

然後在對應聊天室傳一則訊息，系統會嘗試遷移目前 bot/chat 的舊明文資料。
