# 服務中心更新說明

## 更新重點

這包把服務中心的 Telemini Wifi、Gemini API、公告事項補成可用流程。

## 1. Telemini Wifi

使用者在服務中心按下「📶 Telemini Wifi」後，下一則文字會被視為 BotFather 給的 bot token。

流程：

```text
按 Telemini Wifi
→ 貼上 bot token
→ 服務中心刪除 token 訊息
→ Telegram getMe 驗證 token
→ 取得 bot username 當 bot_id
→ 寫入 bot_config
→ 自動 setWebhook 到 BASE_URL/webhook/<bot_id>
→ 回覆設定結果
```

注意：
- 不會把 token 印到 Render log。
- token 寫入 DB 前會嘗試用 `APP_ENCRYPTION_SECRET` 加密。
- 舊版明文 token 仍可相容讀取。

## 2. Gemini API

使用者在服務中心按下「🔑 Gemini API」後，下一則文字會被視為 Gemini API Key。

流程：

```text
按 Gemini API
→ 貼上 Gemini API Key
→ 服務中心刪除 key 訊息
→ 寫入 user_config
→ 清除 gemini_key 快取
→ 回覆設定完成
```

注意：
- 不會把 key 印到 Render log。
- key 寫入 DB 前會嘗試用 `APP_ENCRYPTION_SECRET` 加密。
- 舊版明文 key 仍可相容讀取。

## 3. 公告事項 DB

新增服務中心公告資料表：

```sql
service_center_announcements
```

欄位：

```text
id
ann_key
label
title
body
is_active
created_at
updated_at
```

公告事項按鈕會讀取最新 10 筆公告，最新公告放最上面。

## 4. /start 行為

服務中心 bot 收到 `/start` 時：

```text
先送最新一則公告
再送服務中心主頁按鈕
```

## 5. 本次預設公告

初始化 DB 時會自動補入一則公告：

```text
標籤：功能更新
標題：服務中心與媒體輸入更新
```

## 6. 管理員新增公告

如果有設定 `SERVICE_CENTER_ADMIN_IDS`，管理員可用：

```text
/announce 標籤｜標題｜內容
```

範例：

```text
/announce 功能更新｜小改版｜今天更新了服務中心。
```
