# 圖片等待 10 秒與圖片模型切換修正

## 修改檔案

- `handlers/message_handler.py`
- `services/media_ai.py`
- `services/gemini_service.py`

## 圖片等待流程

```text
收到圖片
→ 立即建立等待狀態
→ 圖片模型解析
→ 解析完成後等待 10 秒
```

- 解析期間收到文字：先暫存；圖片解析完成後立即合併送進文字模型。
- 解析完成後 10 秒內收到文字：取消等待，圖片解析＋文字合併送進文字模型。
- 10 秒內沒有文字：只把圖片解析結果送進文字模型。
- 圖片附註 caption 會一起放進同一次輸入。
- 圖片解析失敗時，如果期間有暫存文字，文字會恢復成一般聊天，不會被吞掉。

## 3.5 Flash 切換修正

原本問題：

- `503 UNAVAILABLE / high demand` 被當成額度用完。
- 因此 3.5 Flash 被停用到隔天，後續圖片直接走 3 Flash Preview。
- 停用狀態原本只按模型記錄，不同使用者可能互相影響。

修正後：

```text
503 / high demand
→ 只重試 3.5 Flash
→ 不停用、不切 3 Flash

一般 RPM / TPM 429
→ 只重試 3.5 Flash
→ 不停用到隔天

明確每日 RPD / per-day 額度用完
→ 只停用該 API Key 的 3.5 Flash
→ 切到 3 Flash Preview

404 / 模型已下架
→ 本次切到 3 Flash Preview
→ 不記成每日額度用完
```

API Key 只使用 SHA-256 短雜湊識別，不會把原始 Key 寫進 log。
