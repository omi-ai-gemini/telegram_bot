# Telemini 文生圖與圖生圖雙模式更新

## 本次改版

### 文生圖

- 不上傳系統基準圖。
- 使用固定男／女人物身份描述。
- 固定採用自然相機、生活感、真實膚質方向。
- 壓低塑膠皮膚、美顏濾鏡、CGI、AI 美女商攝感。
- 依服裝、動作、物品與場景需求自動選擇半身或全身構圖，不再固定生成臉部特寫。

### 圖生圖

- 來源可選本次上傳圖片或聊天室圖片代號／名稱。
- 原圖是最高視覺依據。
- 只修改最新提示詞明確要求的內容。
- 未被要求修改的人物、姿勢、構圖、背景、物品、招牌與文字區域盡量保留。
- 重繪強度由舊版 `0.72` 降為 `0.50`，降低人物與整體畫面漂移。
- 來源圖只做等比例縮放與裁切，不直接拉伸。

## 提示詞優先順序

```text
完全自訂提示詞
或
補充提示詞 > 固定標籤 > 本輪對話
```

程式不再逐項辨識髮型、衣服、場景或物品。
所有需求共用同一條規則：

```text
最新且最明確的要求優先；遇到衝突時忽略較舊內容。
```

補充提示詞會同時放在 Prompt 的最高優先區塊與結尾，降低長對話把補充需求吃掉的情況。

## 重要限制

這版仍是 AI Horde 的 `txt2img / img2img`，不是本機人物分割與精準 Photoshop 合成。

因此：

- 圖生圖會「盡量」保留原圖，不保證中文字能逐像素完全不變。
- 大幅改動姿勢或場景時，原人物相似度仍可能下降。
- 使用者要求改得越少，原圖通常保留得越好。
