# Telemini AI Horde 生圖功能

目前提供兩種模式：

## 文生圖

- 使用固定男／女人物身份描述。
- 不傳送系統基準圖。
- 模型：`Flux.1-Schnell fp8 (Compact)`。
- 預設輸出：`896×1152`。
- 風格為自然相機生活感攝影，避免塑膠肌、過度磨皮、CGI 與純臉部商攝特寫。

## 圖生圖

- 使用本次上傳圖片或聊天室圖片代號／名稱。
- 來源圖等比例處理為 `896×1152`，不直接拉伸。
- 使用 `img2img`，固定重繪強度 `0.50`。
- 原圖是視覺依據；只修改最新提示詞明確要求的內容，其他部分盡量保留。

## 提示詞

不呼叫 Gemini，也不額外消耗 Gemini 圖片解析流量。

優先順序：

```text
完全自訂提示詞
或
補充提示詞 > 固定標籤 > 本輪對話
```

補充提示詞會放在最高優先區塊並在 Prompt 結尾再次強調。

## Render 必填

```text
AI_HORDE_API_KEY_1=第一個 AI Horde API Key
AI_HORDE_API_KEY_2=第二個 AI Horde API Key
BASE_URL=https://你的-render網址
SETTING_LINK_SECRET=設定頁簽章密鑰
APP_ENCRYPTION_SECRET=資料加密密鑰
```

## 任務規則

- 每位使用者最多同時 3 張排隊／生成中任務。
- 排隊與生成合計 20 分鐘超時。
- 圖片與提示詞會送到 AI Horde 社群工作節點。
- 臨時上傳圖只供本次任務使用，不寫入圖片庫。
- 聊天室圖片與完成圖片仍可使用既有圖片庫。
