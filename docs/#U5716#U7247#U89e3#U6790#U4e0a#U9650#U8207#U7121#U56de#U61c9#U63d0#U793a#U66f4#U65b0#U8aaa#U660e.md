# 圖片解析上限與無回應提示更新說明

## 覆蓋檔案

- `config.py`
- `services/gemini_service.py`
- `services/media_ai.py`

## 更新內容

1. 圖片解析單次輸出上限
- 新增 `GEMINI_VISION_MAX_OUTPUT_TOKENS`，預設 `65536`。
- 靜態貼圖解析上限維持 `500`。

2. 圖片解析失敗時不再沉默
- 如果 Gemini 圖片解析沒有輸出文字，聊天室會明確提示：
  - 圖片：`不小心超過單次最大限制，消耗圖片次數1次，文字回應一併停止`
  - 貼圖：`不小心超過單次最大限制，消耗貼圖次數1次，文字回應一併停止`
- 這種情況下不再繼續送進文字模型。

3. 當日額度耗盡也會回提示
- 若圖片解析模型額度耗盡，使用者傳圖時會直接收到提示，不會沒反應。

4. 503 / 高負載不再整天誤判成額度用完
- 只有 quota / 429 / RESOURCE_EXHAUSTED 會停用到下次 Pacific 午夜。
- 503 / high demand 只會本次改試下一個模型。

5. 新增 log
- 會額外印出：
  - 路由選擇
  - 嘗試模型
  - `MAX_TOKENS` 命中 log
  - 全部模型失敗原因

## 可選環境變數

```text
GEMINI_VISION_MAX_OUTPUT_TOKENS=65536
GEMINI_STICKER_MAX_OUTPUT_TOKENS=500
```

## 測試

```bash
python -m py_compile config.py services/gemini_service.py services/media_ai.py
```
