Telemini 副模型真實對話角色修正

問題：
上一版雖然阻止副模型輸出「近期對話紀錄」等 Prompt 文字，
但仍把整份對話塞在 system 區，真正的 user 區只放「直接開始回覆」。
副模型因此沒有把最新一句視為真正的使用者訊息，容易退回客服、助理或說明文語氣。

本次修正：
1. system 區只保留規則、人物、記憶、模式與回覆樣式。
2. 近期對話改用 Llama 3 原生 user / assistant 角色依序送入。
3. 最新使用者訊息會保留為真正的 user role。
4. 移除假的「直接開始回覆。只輸出回覆本體。」使用者訊息。
5. 補強避免客服、秘書、房仲、管家式回覆，但人物設定明確要求時仍可使用。
6. 一般回覆、重跑、接續、/reply 與競速都共用此副模型輸入結構。

修改檔案：
- services/aihorde_text_service.py
- services/reply_model_router.py

驗證：
python -m compileall -q .
